# HealthTrack Alert System — Assignment Scope

Shawn Miller | MSCS-699-B01

This extension adds only the assigned functionality: vital-sign thresholds and patient-specific settings; activity-pattern rules; in-app notifications with severity and low-priority suppression; persistent alerts, authorized acknowledgment, escalation and history; an alert configuration document, tests and results, an integration guide and a performance report.

The system is a fictional educational prototype and is not approved for real patient monitoring. All implementation and test work must integrate with the existing Phase 3 FastAPI project.
